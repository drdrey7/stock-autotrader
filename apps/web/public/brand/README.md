# How Are The Markets brand assets

Production brand assets for the public frontend.

- `logo-horizontal-light.svg` — primary horizontal wordmark for light surfaces
- `logo-horizontal-dark.svg` — primary horizontal wordmark for dark surfaces
- `logo-mark-light.svg` — compact compass/market mark for light surfaces
- `logo-mark-dark.svg` — compact compass/market mark for dark surfaces
- `favicon.svg` — browser/favicon mark
- `apple-touch-icon.png` — iOS home-screen icon

The shell reads these exact public paths through `BrandLogo.tsx`. Keep the filenames stable so branding can be updated without changing application logic or routes.
